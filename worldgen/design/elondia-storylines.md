# 內建世界的故事線規劃（艾隆迪亞）

> 這份是內建世界擴充的故事線藍圖（2026-10 和作者討論定下的方向）。已經做成特殊任務的見第 5 節。
> 角色先做（見 `data/world/npcs.json`），故事線之後照這份逐條設計；做法見 [story-design](story-design.md)。

## 1. 總體結構

### 1.1 一條故事線

- 每條故事線由 **2～3 個特殊任務**組成，等級大致是：
  - 第一個任務：Lv.5～7 接
  - 第二個任務：Lv.8～10 接
  - 第三個任務：Lv.11～13 接
- **開頭**可以用看起來普通的任務慢慢引入（例：教義重新解釋的故事線，從一名牧師的一本筆記開始），也可以直接切入正題（例：安納塔西亞從教國回王國時，馬車遇襲）。
- 任務和任務之間是相對空閒的時間，讓玩家去練等。

### 1.2 主戰與主和

許多故事線的結局會把世界推向**主戰**或**主和**（下表標「⚔／🕊」）。每條會記錄一個劇情旗標，最後由人類方、魔族方各自的多數決定史詩線的走向。

| 勢力 | 主戰派 | 主和派 |
|---|---|---|
| 萊茵帝國 | 四軍團中的主戰將軍 | 皇帝（停戰是他一手促成）、主和將軍 |
| 聖環教廷 | 教廷（整體主戰） | — |
| 晨曦王國 | 皇子阿列克謝 | 公主安納塔西亞 |
| 魔族 | 瓦爾卡斯（若反叛）、血角氏族 | 莉莎爾的律法體制 |

在河谷鎮、沿海渡口這類各國角力的故事線裡，**帝國主和、教廷主戰**，其他勢力照各自的立場。

### 1.3 兩條史詩級故事線（Lv.14～18，切成多個特殊任務）

1. **政治鬥爭的匯流**：人類世界與魔族世界的政治鬥爭，最後匯集成一條史詩線。
   - 人類方、魔族方的**主戰派佔多數** → **開戰路線**：玩家一開始要選陣營，經歷開戰路線的任務。
   - 人類方、魔族方的**主和派佔多數** → **清剿主戰派路線**：去多個城鎮協助清剿主戰派。
   - 兩條路線最後都會引發**龍災**（歷史之龍「回響編年」阿契隆的注視）。
2. **巨龍史詩**：依照之前的選擇，正式解決各地的龍災。
   - 七種龍裡，**觀者之龍「萬瞳凝視」歐瑟拉就是玩家**：那些無所不在、注視著凡世一舉一動的眼睛，是坐在螢幕前的人。
   - **歡愉之龍「眾歡獨樂」莉薇婭**的影響，體現在那些明顯跟奇幻風格不搭的情趣用品上（它們出現在這個世界，就是祂在場的痕跡）。
   - 觀者之龍不寫進巨龍史詩（2026-10 決定）。歡愉之龍後來有了自己的一小段（2026-10-31，「眾歡獨樂」，見第 5 節第三十一批）：在緋夢樂園底下的遺跡，和政治線與龍災無關——祂從來沒有睡過。
   - **龍關注凡人的順序**（2026-10-31 決定）：觀者（玩家）最在乎凡人，歡愉其次（每一個凡人覺得快樂的那一瞬間祂都看見），歷史第三（只在轉折點睜一次眼），其他的龍不知道凡人存在。寫在歡愉秘宮的刻文與世界書「高維巨龍」的推測裡。
   - **巨龍不可名狀**（2026-10 決定）：龍從頭到尾不和凡人溝通——不說話、不回答、不認得任何人，也不會察覺玩家。玩家能做的只有改變身邊的現象（風錘、童謠、夢、荒野、火光），再看龍跟著起什麼變化；龍的動機只出現在祭文、傳說與 NPC 的推測裡。已知的推測：塔之龍只在荒野建塔，因為那裡高的東西少；詭秘之龍迷上的是人們對海與深海的神秘印象；歷史之龍感覺到歷史的轉折點，睜開眼睛看了一眼，這一眼引發了龍災，玩家做的事對祂來說只是被亮光閃了一下，暫時閉上眼睛。腳本 `worldgen/scripts/elondia/dragon_text27.py` 把這條原則寫進了世界書。
3. **路線的分法**（2026-10 決定）：人類方、魔族方的計數器 `human_stance`、`demon_stance` 都至少 1 → 只能走清剿主戰派路線；都至多 -1 → 只能走開戰路線；其他情況（一邊主戰一邊主和、或兩邊都是 0）由玩家在序章自己選。開戰路線要再選陣營（人類方或魔族方）。
4. **頭目的難度**（2026-10 決定）：特殊任務的頭目戰打完要剩 65～70% 的生命，Lv.14～18 的史詩線剩 40～50%（頭目加一隻手下對 4 人隊伍，見 docs/MONSTERS.md）。政治線的三個高潮、終章與巨龍史詩都是頭目戰，輸了可以重試。巨龍史詩接在政治線的終章（Lv.18）之後，所以是 Lv.18～20。史詩的頭目戰在專屬的特殊地圖裡（骸骨要塞的決鬥場、大教堂的鐘樓、天空的裂縫、巴別林的巨塔……，見 docs/SPECIAL_MAPS.md 第 8 節）。任務線裡看起來很強的對手（傳說人物、神靈、古老的守護者、巨大的野獸、親自出手的首領）也是頭目戰，不會兩三下就倒；明顯的小怪（打手、傭兵、刺客、普通野獸）照舊是兩隻小怪。新寫的任務照這個規則挑對手。

### 地下城的故事線

每一座地下城都有自己的故事線，游離在主線與政治線之外（2～3 個任務，照第 1.1 節的等級帶；可以從公會委託、情報商或地下城裡的發現開頭）。題材從世界書的地下城背景與傳說來：

- **可以重試的任務點**：「練好了再來」的戰鬥——地下城線的底層層主戰、鮮血試煉場的三場試煉、戈爾的斧衛考驗——失敗的結果寫 `retry`（照樣顯示失敗的文字，但任務點不結束）。劇情上錯過就沒有的場面（伏擊、暴動、追逐）照舊寫一般的失敗結果，劇情往下走。

- 層主無法溝通，打倒之後會重新出現：原因統一是歷史之龍「回響編年」阿契隆讓地下城反覆重演最深刻的過去（任務的結局寫成半空中閃過交錯的殘影）。低語墓穴、晨霧修道院原本用血誓、封印的說法，已經改成阿契隆。
- 地下城線的戰鬥直接用各層的怪物，不用替身：一（D）在中層、二（C）在深層、三（B）在底層，最後一戰是底層層主。Lv.11 的隊伍打 13 級的底層層主多半會輸，所以這一戰的失敗結果都是 `retry`：輸了任務點不結束，練等之後可以再來挑戰（測試會檢查）。

## 3. 成人向角色與戀愛線（第二部分）

### 3.1 大方向

- **男性向**：戀愛與成人向的對象是女性、偽娘、扶她、TS；**不寫傳統男性與傳統男性**的戀愛或性愛。
- **全部是成年人**：每個角色都在背景寫明二十歲以上（長壽種族寫明「以族人來說已成年」）。嬌小的角色不寫成孩子的樣子。
- **每個人有一種魅力**：強勢的千金大小姐、寂寞的少婦、純情的魅魔、病嬌的賣花姑娘……先想好「這個人迷人在哪裡」，再寫外貌與性格。參考的屬性：大小姐、人妻、熟女、母性、無口、傲嬌、病嬌、天然、女僕、雙胞胎、女忍者、女醫、魔法少女、魅魔、偽娘、扶她、人外娘（史萊姆、幽靈、機偶）、精靈姊姊、女王。
- **個人故事線**：每人一條，大致輕鬆、帶有成人氛圍，最後通向兩人的結合（成為戀人、伴侶、入隊或住進主角的家）。等級照第 1.1 節的帶法，可以比主線短。
- **資料**：這些角色標成「成人向角色」（`adult: true`）；私密部位的描述放在「成人向外貌」。一般角色的關係不寫到成人向角色。
- 第一部分的角色之後也會有戀愛線，放在他們自己的特殊任務裡。

### 3.4 任務的內容警示（已完成）

特定角色的任務線要在接任務前（以及冒險手冊裡）顯示警示，讓玩家自己決定要不要接：

- **NTR**：例如阿雅線的 NTR 分支（媚黑俱樂部）。
- **非處女**：角色在任務開始前就有性經驗，例如人妻（艾蜜莉亞、瑪格麗特、莉澤洛特、克拉拉）、伊蓮娜、卡蜜拉、花魁瑟蕾娜、貝爾維婭（曾被盜賊抓去當玩物）、卡珊卓。

做法（已經做好，見 docs/STORY_QUESTS.md 第 1.2 節）：任務的內容標籤（成人向、NTR、非處女、主角非自願、男性對象），接任務時與冒險筆記顯示成警示；分支型的（只有某個選項會進入 NTR）標在那個選項上。玩家可以在設定裡關掉 NTR、非處女、主角非自願、男性對象（關掉的任務不開放、選項不出現）。
- **對象是傳統男性的親密任務**標上「男性對象」（例如瓦爾卡斯、艾瑟里昂、阿茲爾的「四」），偽娘、中性的角色不標。

- **做給女性主角的任務**（遭到灌醉、色情寶箱怪……）打上「主角非自願」，開頭用「只給這些主角」限定女性形象。
- **戰敗色情事件**本身也算主角非自願：關掉「主角非自願」就不會發生；另外可以設成「男性形象的主角不發生」或關閉。

## 4. 其他種類的特殊任務（之後再談）
