# 內容之間的依賴關係與保護

> 上層：[CONTENT_EDITOR](CONTENT_EDITOR.md)。相關：[SAVES](SAVES.md)（讀檔時的清理）、[STORY_QUESTS](STORY_QUESTS.md)（檢查任務鏈）。
> 程式：`src/engine/usage.ts`（引用檢查；狀態、非戰鬥狀態、能力在 `mods.ts`，商店、地標、特殊地圖、刺青與印記、劇情計數器在各自的 `*Mods.ts`）、`src/engine/mods.ts`（整理與套用）、`src/stores/content.ts`（刪除、改名）、`src/engine/state.ts` 的 `migrate`／`pruneAbilities`／`prunePerks`、`src/engine/story.ts` 的 `pruneStories`。

自訂內容（🌍 世界）可以新增、修改、刪除；存檔在內容改變之後還會繼續用。這份文件列出各種內容互相用到的地方，以及刪掉或改壞時的保護。

## 1. 依賴關係

箭頭表示「A 用到 B」（A → B）。

| 用到別人的（A） | 用到的（B） | 怎麼對應 |
|---|---|---|
| 怪物 | 能力、怪物特性、物品（掉落）、遭遇表（出現地點） | 能力 id、特性 id、物品名稱 |
| 物品 | 底材 × 材料（裝備）、材料（打造連結）、狀態（使用效果）、非戰鬥狀態（吃喝）、工具模板、其他物品（燃料、配方的材料、種子長出的作物）、特質（書籍的 `use.perks`） | id、物品名稱 |
| 制式裝備 | 底材 × 材料 | 自建的底材或材料自動產生，名稱由兩者組成 |
| 底材 | 武器、防具類型 | 內建底材共用武器類型（例：長劍） |
| 固定 NPC | 地點、聚落區塊或特殊地圖（固定格子）、能力、特質、底材 × 材料（裝備）、劇情旗標（出現條件、改變出沒） | id、旗標名稱 |
| 特質 | 其他特質（互斥）、種族與職業（條件）、設施（訓練）、NPC 標籤與職業（抽到的權重）；種族特質依種族自動擁有 | id |
| 能力 | 職業、狀態 | 職業 id（含 `monster`）、狀態 id |
| 狀態 | 其他狀態（命中附加） | 狀態 id |
| 印記設定 | 奴隸印記（預設、老鴇、輕重順序、市場與自賣的權重） | 印記 id |
| 主人的事件 | 刺青圖樣（`tattoo` 效果） | 圖樣 id |
| 地標 | 地點與聚落區塊、特殊地圖（內部）、固定 NPC（場景在場的人）、物品與底材（場景限定的穿著）、劇情旗標 | id、物品名稱、旗標名稱 |
| 商店 | 地點與聚落區塊（位置）、物品（固定清單） | 物品名稱 |
| 職業 | 能力（初始能力） | 能力 id |
| 特殊任務 | 固定 NPC（開頭、地點、敵人、友方、同行、效果）、怪物（戰鬥）、物品與裝備（效果、報酬）、能力（效果）、特質（`perk`、`lose_perk` 效果）、刺青圖樣（`tattoo` 效果）、奴隸印記（淪為奴隸）、其他特殊任務（效果）、地點與設施、臨時地圖、特殊地圖（任務點、傳送）、劇情旗標 | id、物品名稱、旗標名稱 |
| 特殊地圖 | 地點、怪物（遭遇表、BOSS 格）、物品（採集物）、商店、聚落區塊與其他特殊地圖（通道）、劇情旗標（通道的條件） | id、物品名稱、區塊 key、旗標名稱 |
| 旅途事件、情報 | 怪物、特殊任務 | id |
| 旅途與城鎮事件（🎲 事件） | 物品與裝備（效果）、特殊任務（`start_story` 效果）、臨時地圖與特殊地圖（結果的移動）、地點（改道、城鎮事件的地點）、設施與自建商店（城鎮事件的設施）、劇情旗標 | id、物品名稱、旗標名稱 |
| **存檔** | 以上幾乎全部：隊伍的能力、特質（與學特質的機會）與裝備、行囊（物品名稱）、登場過的 NPC、委託（怪物、物品）、情報、特殊任務的進度（任務點 id、旗標）、地圖格子（怪物、資源） | id、名稱 |

### 1.1 局部匯入、匯出用的關聯

`src/engine/contentRefs.ts` 從另一個方向算上面的表：「A 用到誰」。局部匯入、匯出（[CONTENT_EDITOR](CONTENT_EDITOR.md) 第 0 節）選了 A，就沿著它一路帶上全部用到的項目（閉包）。只算世界裡有的項目（自建與修改過的內建）。A 關聯到 B 的情況：

- A 的資料裡（任何深度的字串值或物件的 key）寫了 B 的 id 或名稱；特殊地圖的格子位置寫成 `sm/<id>` 也算。
- A 是物品、B 是掉落它的怪物（掉落存在怪物身上）。
- A 寫了 B（自建的底材或材料）產生的制式裝備。
- A 讀到的劇情旗標（`flags`、`flags_none`、`flags_any`）或計數器（條件的範圍）是 B 寫的（`start_flags`、`set_flags`、`clear_flags`、效果「旗標」、結果的計數器加減）。沒有人寫的旗標（`ai:`、園區印章、其他世界的內容）只提示。

只有一筆的設定（事件設定、印記設定、雙面效應設定、類別圖示）可以被選，但不會因為字串剛好一樣就被當成關聯。

## 2. 刪除時的保護

**自建項目要沒有被用到才能刪**；編輯畫面上方列出用到的地方（🔗），刪除按鈕在有引用時停用。檢查的範圍：

| 刪除 | 會擋下刪除的引用 |
|---|---|
| 怪物 | 特殊任務的戰鬥任務點、特殊地圖的 BOSS 格；目前存檔進行中的委託、有效的情報 |
| 物品 | 特殊任務的效果與報酬、接下時拿到的物品與限定的穿著、地標場景限定的穿著、其他物品的燃料、配方材料與種子的作物、商店的固定清單；目前存檔的行囊、身上的裝備、進行中的委託、房子裡的家具與苗圃上的作物（怪物的掉落會一起拿掉，不擋） |
| 底材、材料 | 玩家建立或修改過的物品（裝備組成、打造材料）、固定 NPC 的裝備、特殊任務的裝備獎勵；底材另外有特殊任務與地標場景限定的穿著；目前存檔身上的裝備與行囊 |
| 固定 NPC | 特殊任務的開頭、地點、敵人、友方、同行、故事裡的死亡、效果；別人小隊的隊員；地標場景的在場的人與好感效果；目前存檔的隊伍、奴隸契約的主人 |
| 特殊任務 | 其他特殊任務的「開始特殊任務」效果、內容是「特殊任務的消息」的情報物品；目前存檔正在進行 |
| 能力 | 職業的初始能力、怪物、固定 NPC（自己的能力與教人的 `teaches`）、主奴與娼館的事件掛的技能、特殊任務的獎勵；目前存檔的角色與升級選項 |
| 狀態 | 技能（施加的狀態）、其他狀態的命中附加、物品（使用時得到、解除、對目標施加）；目前存檔進行中的戰鬥 |
| 非戰鬥狀態 | 酒館菜單、物品與工具、特殊任務、事件、地標、奴隸生活的事件、其他非戰鬥狀態的疊加或取代；目前存檔身上有這個狀態的角色 |
| 特質 | 固定 NPC 的特質清單、特殊任務的 `perk`／`lose_perk` 效果、書籍（`use.perks`）、其他特質的互斥；目前存檔的角色、學特質的機會、登場過的人（內建特質包括種族特質都不能刪） |
| 刺青圖樣 | 特殊任務的 `tattoo` 效果、主人的事件（角色身上的刺青是自己的一份，不擋） |
| 奴隸印記 | 印記設定（預設、老鴇、輕重順序、市場與自賣的權重）、特殊任務的「主角淪為奴隸」（身上的印記與市場上的商品不擋：印記存自己的一份，商品的模板不見時用預設的） |
| 自建地標 | 特殊任務的任務點（`at.cell`）、待在這裡的固定 NPC（`landmark`）；特質的受訓地點刪除時一起拿掉 |
| 自建特殊地圖 | 特殊任務的任務點（`at.special_map`）與傳送（`special_map`）、其他地圖接過來的通道、地標的內部（`interior`）、站在這裡的固定 NPC（`fixed`，含依劇情旗標改變出沒的各組） |
| 自建事件 | 不擋（沒有別的內容指到事件）；存檔裡等待中的這個事件作廢，旅途上那一格算是過了 |
| 自建主奴與娼館的事件 | 不擋；等待回應中的這個事件作廢（事件視窗顯示「略過」） |
| 自建劇情計數器 | 特殊任務、事件、固定 NPC 的條件與結果（`counterMods.ts` 的 `counterUsage`） |
| 自建商店 | 擺了這家店的特殊地圖、擔任店主的固定 NPC（特質的受訓地點刪除時一起拿掉；存檔裡這家店的庫存與生成的店主不擋，格子變回道路） |

**其他存檔**要等讀檔時才知道，所以讀檔（以及自訂內容改變之後）會清理：

- 不存在的能力從角色、升級選項與進行中的戰鬥拿掉。
- 不存在的狀態從進行中的戰鬥拿掉（`pruneStatuses`）。
- 不存在的特質從角色、學特質的機會（沒有選項又不能寫說法的機會整個拿掉）與登場過的人拿掉（`prunePerks`）；角色身上的自訂特質寫在角色資料裡，不受影響。
- 不存在的特殊任務：進行中的算中斷，任務同行的夥伴離隊（不會一直佔著同行的名額）。
- 不存在的旅途、城鎮、地下城事件或寄生物的發作：等待中的作廢（`pruneRoadEvent`、`pruneTownEvent`、`pruneDungeonEvent`、`pruneParasiteEvent`），不會卡住不能走。
- 不存在的特殊地圖：從存檔作廢，主角正在裡面時送回進來前的地方（`pruneSpecialMaps`，[SPECIAL_MAPS](SPECIAL_MAPS.md) 第 7 節）。
- 底材或材料不存在的裝備：留在身上或行囊裡，但**沒有效果、不能裝備**，說明顯示「已失效」（不會讓遊戲壞掉）。

## 3. 改名

- **自建物品改名**：怪物的掉落、特殊任務的效果與報酬、其他物品的配方材料與種子的作物、目前存檔的行囊、身上的裝備名稱、進行中的委託、房子裡的家具與作物一起改。其他存檔裡的會變成無法使用的雜物。其他物品的燃料（`tool.fuel`，例如油燈的燈油）與商店的固定清單也一起改。
- 物品名稱不能有 `|`、`*`（打造指令用的分隔符號），不能和內建、自建、目前存檔裡 AI 生成或打造的物品同名。
- **底材、材料改名**：制式裝備的名稱跟著改；之後打造、寶箱、掉落的制式品如果目錄裡沒有同名同組成的物品，會另外登錄（仍然可以裝備）。

## 4. 修改的限制

- **內建底材**：欄位、材料類型、雙手不能改（存檔裡的裝備、職業起始武器、制式裝備都靠它們）；匯入的檔案也會被改回來。
- **內建材料**：類型與等級不能改（隨機裝備、起始裝備、NPC 配備依「類型 × 等級」找材料）。就算某一級的材料不見了，也會改用最接近的那一級，不會壞掉。
- **數字欄位留空**：用預設值（以前會變成 0 再被夾到最小值，例如價格變 1）。
- **乾糧**：雜貨店直接買乾糧的價格跟著目錄（不能低買高賣）。
- **特殊任務：檢查任務鏈分成錯誤與提醒**（`storyMods.ts` 的 `storyCheck`）。
  - **錯誤擋儲存**（編輯器的儲存按鈕、`stores/content.ts` 的 `saveStory` 都擋）：引用的固定 NPC、怪物、物品、裝備的底材或材料、特殊任務、特質、主人、要同行或離開的角色、特殊地圖的任務點的地圖不存在；沒有任何結果會完成任務；地點類型不對（近郊選了地下城、地下城那一層選了聚落、聚落或設施選了地下城）；任務點沒有指定地點；開頭的城鎮沒有公會或情報商、任務點的地點沒有那種設施；戰鬥沒有敵人；選擇沒有選項；同一個角色同時是友方與敵對；開頭旗標和別的任務一樣（兩個任務的任務點會互相觸發）；效果開始的是這個任務自己。
  - **提醒不擋**：需要的旗標在任務裡沒有地方設定（可能由 AI 判定或其他任務設定）；開頭是「只由其他事件開啟」卻沒有任務開啟它；任務點不會解鎖、沒有任何一條路走得到完成、選了某個結果之後可能沒有任務點可以進行（`storyReach.ts`，見 [STORY_QUESTS](STORY_QUESTS.md) 第 3 節）。
  - **匯入**：匯入內容檔、匯入存檔時合併附帶的內容，有錯誤的特殊任務不收（`mods.ts` 的 `dropBrokenStories`，拿掉一個可能讓別的變成有錯誤，會反覆檢查），內容頁籤上方列出沒匯入的任務與原因；合併時這個瀏覽器原本的版本保留。
  - **複製任務**：開頭旗標換成新任務自己的（`copyStory`），所以複製來的任務不會撞旗標。
- **特殊任務：會弄壞目前存檔進度的修改擋儲存**（內建與自建都一樣，`storyMods.ts` 的 `progressBreaks`）。目前的存檔正在進行這個任務時：
  - 完成過的任務點 id 被改掉或刪掉（改了會被當成新的任務點，再觸發一次）；
  - 修改前至少有一個解鎖、沒完成的任務點（依目前的旗標與完成紀錄），修改後一個都沒有，而且其他進行中任務已解鎖的任務點也沒有結果會設定（或清除）它們缺的旗標（`ai:` 旗標算 AI 之後可能設定）。
  - 編輯器顯示原因與兩個選擇：「📄 複製成新任務再改」（修改存成新的任務，原本的不動）、「放棄這個存檔的任務進度後儲存」（同冒險筆記的放棄）。修改前就已經卡住的不擋。

## 5. 執行時的保護（舊存檔、匯入的檔案）

- 裝備的底材或材料不存在：數值、武器與防具類型略過，不會丟錯。
- 效果要加入的固定 NPC 不存在或已經在隊伍裡：略過（以前會讓任務點卡住）；只有入隊本身出錯時才在日誌註明。
- 效果的裝備底材或材料不存在：略過。
- 物品的打造連結指到不存在的材料：拿掉。
- 讀取保存的自訂內容時，自建的狀態最先登錄（自建的狀態彼此也可以互相引用），再來是能力、底材與材料，物品、固定 NPC、任務裡用到它們的地方不會被誤刪。

- 已經生成的地圖上，遭遇格的怪物整組被刪掉：換成這個地方現在的遭遇（層主換成這一層現在的層主，強敵換成最強的一組再多一隻）；旅途上的遭遇換成這段路的遭遇。真的找不到才當成已清除（情報點會跟著結束）。

### 依內容算出來的快取

有些東西每走一步都要查好幾次，改成依內容算一次就記住：用到每個地標的特殊任務（決定只有場景的地標要不要留在地圖上）、小隊表（誰是哪個小隊的隊長、隊員）、城鎮各區塊的基底地圖（`grid.ts` 的 `baseBlock`：地圖字元、世界設定擺的商店與地標）、特殊任務依開頭分類（`story.ts` 的 `storyStarts`：公會的任務、每位固定 NPC 的任務，「這裡可以接的特殊任務」只檢查這幾個）、特殊地圖定義的版本（`specialVersion`，依定義物件記住）。這些只跟遊戲資料有關，不寫進存檔。

- 城鎮地圖每次取用時，依存檔疊上的房子、通道、隱藏的地標照舊即時算（都是換掉整格），快取每次給一份新的格子陣列，不會被改到；地標、商店換位置（`invalidateBlocks`）時也會重建。
- 畫面上「現在所在的地方」（這裡的人、所在的區域與格子）由遊戲的 store 共用（`game.here`、`game.area`、`game.cell`，Vue 的 computed），各面板不再各自重算。特殊任務面板的「可以接的任務」「這裡的任務點」「要等時段的任務點」也用 `game.here`，後兩者共用同一份進行中的任務點。
- 任務依開頭的分類除了內容版本，還逐筆比對任務清單（測試直接加、換任務也會重算）；特殊地圖的版本依定義物件記住，世界設定換定義時是一份新的物件，**原地改定義的欄位不會被偵測**（要換成新物件或 `bumpContentRevision()`）。

- 套用世界設定（`applyContent`）或還原成內建時，`data.ts` 的內容版本（`contentRevision`）加一；快取看到版本變了就重算，所以切換世界、在世界頁籤存檔、讀不同世界的存檔之後都是最新的。
- 程式或測試**直接改資料**（不經過 `applyContent`）時，要呼叫 `bumpContentRevision()`，不然快取還是舊的。

## 6. 脫困的方法

- **放棄一般委託**：冒險筆記的「一般委託」每一件都有「放棄」（公會聲望 -1）。目標怪物或物品被刪掉、委託永遠完成不了時可以用。
- **放棄特殊任務**：冒險筆記的「特殊任務」（原本就有）。

## 7. 還沒處理的風險

討論後暫時不處理的項目，記在 [LOGIC_ISSUES](plan/LOGIC_ISSUES.md) 的 L2、L3。
