# 城鎮的特色地標

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[WORLD](WORLD.md)（聚落地圖）。被依賴：[STORY_QUESTS](STORY_QUESTS.md)（任務點）、[NPC_SYSTEM](NPC_SYSTEM.md)（固定 NPC、生成居民的分布）、[CONTENT_EDITOR](CONTENT_EDITOR.md)（地標頁籤）。
> 資料在 `data/world/landmarks.json`（類型與地標）。程式：`src/engine/landmarks.ts`（遊戲中的功能）、`src/engine/landmarkMods.ts`（內容編輯器）、`src/engine/grid.ts`（擺上地圖）。

## 1. 地標是什麼

聚落地圖上的一格，代表那座城的特色建築（騎士學院、聖環主殿、舊石橋……）。**格子的種類就是地標的 id**（`lm_` 開頭），所以所有用「格子種類」指定地方的系統都可以直接指定地標。一個地標只在一處。

- 內建 111 個（西大陸 79 個，炎華之地 32 個）。西大陸：地下街（[SPECIAL_MAPS](SPECIAL_MAPS.md) 第 9 節）的黑市 6 個與地下淫鬥場 12 個擺在特殊地圖裡；其餘是世界書各區域條目的「特色建築」32 個，加上世界書沒寫到的聚落由本專案補寫 12 個（月輝之母、生命之泉、七潮議會廳、深潮席渡口、海靈祠、渡口燈塔、花崗岩城牆、風錘、變異藥沼、森語之環、浮石觀星台、長老石廳）；再加上故事線解鎖的特殊區域 6 個（第 6 節）、打工線委託人的地標 9 個（黃金骰子賭場、克勞澤伯爵府、怪人之塔、朝聖者澡堂、珍珠澡堂、熔岩溫泉旅館、下城區的按摩店、河畔的畫室、侍寢見習館），以及緋夢樂園的售票亭（[LUST_PARK](LUST_PARK.md)）與月下拍賣會（第 6 節）。後面這 17 個都是成人向的場所。緋夢樂園的主題體驗區另外 11 個（成人向，[LUST_PARK](LUST_PARK.md) 第 9 節）：入口廣場上的閘門、體驗區裡的五座體驗館，與每一館裡通往第二層的門（共 122 個）。炎華南域（東大陸）24 個：原本的 19 個是龍安府的御街夜市、瓦舍勾欄、太學與貢院、太廟，皇城裡的宣德樓、尚寢局、太妃宮；萍江府的虹橋、竹湖、織造局、萍園（內部：藏瓷閣）、靈虛觀；瑔州港的蕃坊、胡記商號、金玉行、市舶司、火藥坊；青丘屯的仙堂（內部：仙堂的內堂）、老榆樹；R26 的打工線另外加了 4 個（狀元客舍、畫舫碼頭、珠船塢、大車店的大炕），還有瓦舍的無面樓（蘇婉貞的 NTR 線解鎖的特殊區域，成人向，內部是同名的特殊地圖）。炎華北原 8 個：金帳王庭的金帳、那達慕場、敖包、南院大帳；鷹河榷場的茶馬市、鷹房（內部：海東部的冬營）、驛站、野馬帳（燁婉寧的 NTR 線解鎖的特殊區域，成人向，內部是同名的特殊地圖）。炎華南域的受訓：太學（博學）、靈虛觀（虔誠、意志堅定）、胡記商號（生意頭腦）、火藥坊（巧手、機關老手）。
- 每個地標：名稱、圖示、說明（地點面板顯示）、**氛圍**（站在這裡行動時交給 AI）、**類型**（最多 4 種）、位置（區塊 key 與座標，要是道路，不能是待售的空地；也可以是同一個聚落的固定特殊地圖 `sm/<id>` 上畫的空地，例如地下街，見 [SPECIAL_MAPS](SPECIAL_MAPS.md) 第 9 節）。
- 擺法：建立聚落區塊時疊在道路上（`grid.ts` 的 `buildBlock`，在商店的位置之後）；不改 `maps.json`，所以舊存檔讀進來也看得到。地標可以走過去，不會擋路。

## 2. 類型

| 類型 | id | 聚到這裡的居民 |
|---|---|---|
| 聖地 | `holy` | 一般人、神官與主教（很高）、好人 |
| 學院 | `academy` | 一般人、冒險者、貴族 |
| 官府・議會 | `official` | 貴族、皇族 |
| 軍事・校場 | `military` | 冒險者 |
| 市集・交易 | `market` | 一般人、商人、旅人、惡人 |
| 工坊 | `workshop` | 一般人 |
| 碼頭・渡口 | `harbor` | 旅人、商人 |
| 古蹟 | `monument` | 一般人、冒險者、旅人 |
| 自然 | `nature` | 一般人 |
| 陰森之地 | `haunted` | 惡人 |

權重在 `landmarks.json` 的 `types[].npc`（`commoner`、`adventurer`，`tags` 是帶這些標籤的人）；一個地標有好幾種類型時取最高的（`population.ts` 的 `landmarkWeight`）。

## 3. 用途

| 用途 | 說明 |
|---|---|
| 特殊任務的任務點 | `at.where = cell`、`at.cell = 地標 id`（地標要在 `at.location` 那個聚落）；編輯器的設施清單會列出這個地點的地標 |
| 固定 NPC 的站點 | 出現的方式選「待在地標」（`NpcDef.landmark`）：站在地標那一格，地標搬家時跟著走；依劇情旗標搬走時看那一組的設定 |
| 生成居民的分布 | 依類型（第 2 節） |
| AI 的場景 | 站在地標上做主動行動時，場景加上「・地標名稱（氛圍）」（`withLandmark`） |
| 公會委託 | 第 4 節 |
| 參訪、探索、打工、受訓、開放條件 | 第 5 節 |
| 場景（解鎖的特殊區域） | 第 6 節 |

## 4. 公會委託的標的

`town_quests.json` 的範本可以寫 `landmark`（地標類型的清單）。委託板更新時，城裡有符合類型的地標，這種範本才會進候選（還沒出現的地標與成人向的場所不算）；選中時從符合的地標隨機挑一個：

- 委託記住地標（`Quest.landmark`），標題與場景的 `{landmark}` 換成地標的名字；
- 執行地點就是那個地標（`town.ts` 的 `questSpot`）；地標被刪掉時改回範本的設施（沒有寫時是公會）。

| 範本 | 類型 | 種類 |
|---|---|---|
| 清除{landmark}地下的巨鼠 | 古蹟、陰森、工坊、碼頭 | 戰鬥（巨鼠 ×3） |
| 在{landmark}守夜 | 聖地、古蹟、官府 | 巡邏 DC 11（可能遇到盜賊） |
| 調查{landmark}夜裡的怪聲 | 陰森、古蹟、聖地 | 尋找 DC 12（可能遇到墓鼠群與食屍鬼；有機會學到能力） |
| 替{landmark}的學者找齊資料 | 學院 | 尋找 DC 12（有機會學到能力） |
| 在{landmark}幫忙卸貨 | 碼頭、市集 | 送貨 |
| 揪出在{landmark}出沒的扒手 | 市集 | 尋找 DC 12（可能遇到盜賊） |
| 替{landmark}搬運礦石與燃料 | 工坊 | 送貨 |
| 維持{landmark}儀式的秩序 | 聖地、官府 | 巡邏 DC 10 |
| 在{landmark}擔任陪練對手 | 軍事 | 巡邏 DC 12（有機會學到能力） |
| 在{landmark}一帶採集藥草 | 自然 | 採集 DC 10（藥草 ×2） |

報酬照 F 級（30～50 白鸛）。每座城一次發的城內委託從 3 個增加到 4 個，讓一般的委託不會因為多了地標委託而變少。

## 5. 地標的功能

每個地標可以有下面幾種功能（都可以在內容編輯器設定），站在地標上時地點面板會列出來。

| 功能 | 說明 |
|---|---|
| **開放條件**（`open`） | 只在白天（6～18 時）或只在夜裡；劇情旗標成立（而且那些不成立）時；這裡的勢力至少要有多少聲望；官方場所（逃亡奴隸不能用）。不開放時不能參訪、探索、打工與受訓（公會委託照樣可以做）。勾了「條件不成立時不顯示」（`hidden`），旗標的條件成立之前地圖上是普通的道路（例如完成任務才開幕的店、秘密俱樂部）；勾了「成人向的場所」（`adult`），不當公會委託的地點 |
| **參訪**（`visit`） | 不用檢定：付錢（`money_cc`）、花時間（`hours`），得到效果；隔幾天才能再來（`cooldown_days`，預設每天一次）。例如晨曦聖殿「在祭壇前祈禱」得到祝福 |
| **探索**（`explore`） | 主動行動 `explore`：照設定的屬性與 DC 檢定，成功（含大成功）得到 `effects`，大成功另外得到 `critical`；隔幾天才能再試（預設 7 天，失敗也算）。AI 判定與寫經過時知道地標的氛圍 |
| **打工**（`work`） | 和設施的工作一樣（[WORK](WORK.md)），名稱是「地標名稱的雜務」 |
| **受訓** | 寫在特質的受訓地點（`perks.json` 的 `train.cells`）；地標的編輯表單可以直接勾選 |
| **黑市**（`black_market`） | 站在上面時看得到這座聚落不公開的奴隸買賣與今天的珍品（[COMPANIONS](COMPANIONS.md)）；內建的都在地下街裡 |
| **淫鬥場**（`arena`，成人向） | 站在上面時可以報名三種擂臺（[LEWD_STATS](LEWD_STATS.md) 第 21 節）；內建的都在地下街裡 |

參訪與探索的效果可以用：金錢、物品、裝備、經驗值、聲望、親密度、記憶、學會能力、生命值、特質的機會、非戰鬥狀態、刺青（不能讓主角淪為奴隸、開始特殊任務或讓人入隊）；最多 6 個。存檔記錄每個地標上次參訪、探索是第幾天（`GameState.landmarks`）。

## 6. 場景

地標可以有幾個**場景**（`scenes`，最多 12 個；2026-11-09 從 8 個提高）：條件成立時出現在地點面板的固定場景，例如故事線解鎖的特殊區域。程式：`landmarks.ts` 的 `scenesHere`、`sceneBlocked`、`playLandmarkScene`；欄位見 [worldgen/guides/landmarks](../worldgen/guides/landmarks.md) 2.3 節。

- **出現的條件**：內容標籤（設定關掉的不出現）、主角的形象（`pc_body`：男性形象、女性形象、中性；設定打開「陽剛體型也能遇到『只給陰柔、中性』的成人內容」時，不含男性形象的限定也給男性形象，見 [ADULT_EVENTS](ADULT_EVENTS.md)「陽剛體型」）、劇情旗標（`requires`）；一定在場的固定 NPC 死了或被抓走時也不出現。勾了「條件成立前不顯示」、只有場景的地標（沒有參訪、探索、打工）一個場景都不出現時，地標本身也不出現（地圖上是普通的道路）；沒勾的在還有接得到或進行中的特殊任務要用到時照常出現（例如打工線委託人的地標：任務點在那裡，完成之後才有場景），都沒有時也不出現。
- **在場的人**（`cast`）：寫了旗標的人，旗標成立才在場；有人不在場時接上代替的人（`extras`，例如「其他不知名的魅魔」）。經過裡的 `{cast}` 換成在場的人，在場的每個人加 `affinity` 好感。
- **冷卻**：預設每 3 天一次，同一個地標的場景共用；勾了自己算冷卻（`own_cooldown`）的另外算（例如女僕咖啡廳前廳的喝茶，每天一次）。存檔記在 `GameState.landmarks[id].scene`、`.scenes[場景名稱]`。
- **內部**（`interior`）：地標可以指定一張同一個聚落的固定特殊地圖當內部。地標格變成入口（地點面板的「走進…」，地標不開放時不能進），從地圖的出口離開時回到地標格。寫了格子（`spot`）的場景只在內部的那一格出現，地圖上畫一顆心、格子名稱用 `spot_name`；沒寫格子的場景還是在外面的地標格上。`interior_story`：內部只在有進行中的特殊任務點擺在裡面（任務點的地點是那張特殊地圖）時進得去，其他時候按鈕寫「沒有事要辦時進不去…」；冒險筆記寫出從哪個地標進去（金帳王庭的「金帳」→ 金帳的內帳、龍安府的「宣德樓」→ 宣德樓的城樓、瑔州的「珠船塢」→ 赤鬟的走私船艙：被召見才進得去，離開了也能回去把事辦完；地標在王城裡時，被召見的期間王城的衛兵放行（`summonedInto`），官方機構也不因為逃亡奴隸的身分擋人；`innerTent.spec.ts` 檢查每一張有任務點在裡面的特殊地圖都有地標或通道進得去）。
- **拍賣會**（`auction`，成人向）：地標的面板多了今晚的拍品、出價與寄賣（[LEWD_STATS](LEWD_STATS.md) 第 26 節）；目前是阿爾貝納地下街的「月下拍賣會」。
- **限定穿著**（`wear`）：物品名稱或裝備底材，主角沒穿上時按鈕停用並說明（和特殊任務的任務點一樣，見 [STORY_QUESTS](STORY_QUESTS.md)）。
- **身分**（`role`）：主角或隊上的夥伴符合條件就能參加，見 6.1 節。
- **結果**：付錢、花時間、得到效果；報告交給 AI 寫經過，標了成人向的場景帶上 `narration.adult_scene`，照成人場景規則詳細描寫。

### 6.1 身分：誰來當

場景可以寫一個**身分**（`role`），例如緋夢樂園的「精牛乳牛」「苗床」「表演者」（[LUST_PARK](LUST_PARK.md) 第 9 節）。程式：`landmarks.ts` 的 `roleMembers`、`roleNote`。

- **條件**（都寫了就都要符合）：限定穿著（`wear`，物品名稱或底材，和上面的限定穿著一樣）、曝露度至少多少（`exposure`，0～3，[LEWD_STATS](LEWD_STATS.md) 第 3 節）、正在泌乳（`lactating`）、身體會泌乳（`can_lactate`，[FAMILY](FAMILY.md) 第 10.1 節）、身上有怪物的苗床（`brood`）、只有主角（`pc_only`）、只給這些體型（`body`，看那個人自己的體型；和 `pc_body` 一樣，設定打開「陽剛體型也能遇到『只給陰柔、中性』的成人內容」時陽剛體型也算）。暫時離隊的人不算。
- **誰參加**：隊伍裡符合條件的人**全部一起**（主角或夥伴都可以，主角不一定要參加）；一個都沒有時按鈕停用，寫出缺什麼（「隊伍裡要有人穿著【乳牛比基尼】……才能當精牛乳牛」）。地點面板寫「當精牛乳牛：你、某某」。
- **經過**：`{role}` 換成參加的人（主角寫「主角」），交給 AI。
- **效果**（`role.effects`）：每個參加的人**各一份**，對象換成那個人（狀態、生命、慾望指標、泌乳、經驗……）；錢、物品照人數給。寄生物只給主角（苗床只有主角），所以效果寫了**苗床**的身分只有主角能當，主角現在不能成為那個苗床（篩選關著、懷孕中、已經有了、胎生沒有子宮……）時按鈕停用並寫原因。場景本身的 `effects` 照舊給主角。
- **走進內部的條件**（地標的 `enter`）：`enter.role` 寫了時，隊伍裡要有人符合才走得進去（「走進…」停用並說明）；符合的人走進去時各得到 `enter.role.effects`，寫一則日誌（`enter.text`，`{role}` 換成他們）。例如淫植花園的花粉溫室：曝露度 3 才進得去，一進去就發情、敏感。
- 場景、身分可以用的效果：金錢、物品、裝備、經驗、聲望、親密度、記憶、技能、生命、特質、非戰鬥狀態、刺青，以及給成人向場景的慾望指標、泌乳、寄生物（苗床）。
