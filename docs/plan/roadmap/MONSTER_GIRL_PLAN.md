# 魔物娘與擴大發情：計畫

> 上層：[未來計畫](../ROADMAP.md) R14。相關：[MONSTERS](../../MONSTERS.md)（怪物一覽）、[COMBAT_SYSTEM](../../COMBAT_SYSTEM.md) 8.2 節（特徵）、[ADULT_EVENTS](../../ADULT_EVENTS.md)（戰敗事件、陽剛體型）。
> 目的：補足陽剛體型主角的成人內容。打開「魔物娘」設定時，送給 AI 的怪物描述換成魔物娘的版本；同時讓更多怪物會發情（會在戰敗後起意）。
> 現況：清單整理完（2026-11-01），還沒開始做。第 2～7 節的清單由 `data/rules/enemies.json` 與各遭遇表算出（241 隻在近郊、旅途或地下城出現的怪物，旅途的遭遇用的是各地區的近郊表）。

## 1. 規則（已決定）

1. **幼體、年幼**：沒有魔物娘形態。
2. **主題園區**（緋夢樂園的五座園區，以及之後的禁果庭園、歡愉秘宮）：整個排除。
3. **擴大發情**：人形（哥布林這類、人類）、魔族、妖精、元素、構裝，以及有觸手功能的植物，都普遍允許發情；**排除不死生物與節肢動物**。新加的發情只在近郊、旅途、地下城的遭遇擲，特殊任務的戰鬥不擲（除非任務自己要求）。
   - 野獸、靈體不在例子裡，但排除的只有不死與節肢，所以先當成允許（第 8 節待確認）。
   - 另外排除：一整群的（蝙蝠群、鴉群）、只有部位的（觸手）、亡魂類的靈體（比照不死）、沒有形體的（聲音、意志、陣法、門、原石）、映照你自己的、體型嬌小的（巴掌大的小惡魔、小精靈，比照年幼）。
4. **怪物清單**（世界 → 怪物）加上「發情」與「魔物娘」兩個篩選，和現有的種類、出沒篩選並列。
5. **會發情的怪物都要有魔物娘形態**（主題園區除外）。
6. 先列清單（本文件），確認後再動手。
